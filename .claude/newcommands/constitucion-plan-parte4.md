# Comando: Plan Parte 4

## Tu Tarea

Crear plan detallado de **Parte 4: Razonamiento de Elecciones** (justificación de cada decisión de Parte 3).

## Input

1. Plan maestro
2. **Parte 3 escrita** (contiene todas las decisiones numéricas)
3. Partes 1 y 2 (para conexión de argumentos)
4. Notas (contienen razonamientos del usuario sobre trade-offs)

## Objetivo de Parte 4

**Justificar CADA decisión numérica de Parte 3.**

Para cada número (%, días, umbrales):
- ¿Por qué ese número y no otro?
- ¿Qué trade-offs se consideraron?
- ¿Qué alternativas se descartaron?
- ¿Qué riesgos tiene este número?

**Tono:** Transparente, honesto sobre limitaciones, no defensivo.

**Debe reconocer:**
- Que estos números son propuestas, no verdades absolutas
- Que hay trade-offs en cada decisión
- Que otras elecciones pueden ser válidas con diferentes prioridades

## Proceso

1. Lee Parte 3 completa
2. Extrae TODAS las decisiones numéricas
3. Para cada decisión, busca en las notas el razonamiento del usuario
4. Organiza por tipo o por tema
5. Planea estructura de justificaciones

## Output

Escribe: `/obra-constitucion-democratica/planes/plan-parte-4.md`

**Formato:**

```markdown

## Formato de Cada Justificación

Para cada decisión:

```markdown

[Por qué este número específico - 2-3 párrafos]

- Si hubiéramos elegido [más alto]: [ventaja] pero [desventaja]
- Si hubiéramos elegido [más bajo]: [ventaja] pero [desventaja]
- Elegimos [valor] porque priorizamos [X] sobre [Y]

**Riesgos de esta decisión:**
[Qué puede salir mal con este número - ser honesto]

**Contexto importa:**
[En qué situaciones este número debería ajustarse]
