# Comando: Plan Parte 1

## Tu Tarea

Crear plan detallado de **Parte 1: La Constitución Democrática** (solo principios, NO implementaciones).

## Input

1. Plan maestro (outline general de Parte 1)
2. Grafo de conceptos + archivos md de conceptos
3. PLAN-SISTEMA-AGENTES.md (para recordar objetivos)

## Objetivo de Parte 1

**Articular principios constitucionales universales aplicables a cualquier nación.**

Características:
- Solo PRINCIPIOS, no implementaciones específicas
- Lenguaje universal (no específico de un país)
- Fundamentado en naturaleza humana y organización social
- Base teórica para las demás partes

**NO debe incluir:**
- Números específicos (%, días, umbrales)
- Nombres de países (salvo ejemplos ilustrativos breves)
- Implementaciones concretas

**SÍ debe incluir:**
- Qué debe existir (revocación, separación de poderes, etc.)
- Por qué debe existir (brevemente)
- Cómo se relacionan los principios entre sí

## Proceso

1. Del plan maestro, toma el outline de Parte 1
2. Expande cada sección con los conceptos correspondientes del grafo
3. Define flujo lógico: ¿Qué se explica primero y por qué?
4. Asegura que solo hay principios (sin implementaciones)
5. Identifica qué archivos .md de conceptos se necesitan para cada sección
